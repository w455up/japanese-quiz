# 日文單字測驗機（本機版）

抓取 [sigure.tw](https://www.sigure.tw/) 日文單字頁面（N1~N5 皆可）建立自己的題庫，
在本機做「中文 → 打假名」「日文 → 打假名」的測驗，答案詳解含正確假名、重音與發音（瀏覽器內建語音合成）。

## 第一次使用

```
Setup.bat
```

會建立虛擬環境並安裝套件。

## 啟動

```
RunMe.bat
```

啟動後瀏覽器會自動開啟 http://127.0.0.1:8787

## 使用方式

1. 「題庫管理」分頁貼上單字頁面網址（例如 `https://www.sigure.tw/learn-japanese/vocabulary/n4/01`），
   一行一個，可一次貼多個單元，按「抓取並加入題庫」。
2. 切到「開始測驗」分頁，勾選要考的單元、選出題模式（中文→假名 / 日文→假名 / 混合）與題數，按「開始測驗」。
3. 作答時直接輸入平假名/片假名，按 Enter 送出；再按一次 Enter 進下一題。
4. 每題答完會顯示正確答案（日文、假名、重音、中文）並自動唸出發音，也可按「播放發音」重聽。

題庫存在 `data/questions.json`，重複抓取同一單元會自動更新既有資料、不會重複。

> 僅供個人學習使用，單字內容版權屬於 sigure.tw；本工具不轉錄該網站的音檔，發音一律用瀏覽器內建的日文語音合成。
